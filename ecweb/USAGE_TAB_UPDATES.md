# 用量Tab页面更新说明

## 更新时间
2026-06-15

## 最新更新（第二轮）

### 1. 花费卡片宽度调整
- 总花费卡片的宽度设置为其他卡片的1.5倍，更加突出显示

### 2. 会话数和消息数支持时间范围过滤
**重要改进**：现在会话数、收到消息数、发出消息数都支持按时间范围统计

- **会话数**：根据会话文件的修改时间（mtime）进行过滤
- **消息数**：根据每条消息的时间戳（ts）进行过滤
- 所有三个指标（会话数、收到消息、发出消息）现在都会随着时间范围选择而动态变化

这意味着：
- 选择"今日"可以看到今天的会话数和消息统计
- 选择"本周"可以看到本周的会话数和消息统计
- 其他时间范围同理

## 主要改动

### 1. 移除仪表板（Dashboard）子标签
- 删除了"仪表板"这个子tab页面
- 现在用量tab只包含两个子标签：
  - **总览（Overview）**
  - **详细统计（Explorer）** - 原"浏览器"更名

### 2. 总览页面支持日期区间选择
新增了6种日期范围选择：
- **今日** - 显示今天的数据
- **本周** - 显示本周一到今天的数据
- **上周** - 显示上周一到上周日的数据
- **本月** - 显示本月1号到今天的数据
- **最近30天** - 显示最近30天的数据
- **自定义** - 可以选择任意日期范围

### 3. 卡片重新分组
数据卡片按功能分为三个组，每组有独特的颜色标识：

#### 会话组（蓝色）
- 会话数
- 收到消息
- 发出消息
- 模型调用总次数

#### 用量组（绿色）
- 输入Token
- 输出Token
- 缓存创建
- 缓存命中
- 缓存命中率

#### 花费组（橙色）
- 总花费

### 4. 缓存命中率计算规则修正
**新公式：**
```
缓存命中率 = 缓存命中 / (缓存命中 + 缓存写入 + 输入token + 输出token)
```

**旧公式：**
```
缓存命中率 = 缓存命中 / (缓存命中 + 输入token)
```

新公式更准确地反映了缓存在所有token使用中的占比。

## API变化

总览接口现在支持查询参数：
- `from` - 起始时间戳（毫秒）
- `to` - 结束时间戳（毫秒）

示例：
```
GET /api/stats/overview?from=1718380800000&to=1718467199999
```

## 用户体验改进

1. **更清晰的信息层次** - 通过颜色分组，用户可以快速识别不同类型的指标
2. **灵活的时间范围** - 用户可以查看任意时间段的数据，不再局限于全时段
3. **更准确的指标** - 缓存命中率计算更科学
4. **简化的界面** - 移除冗余的仪表板，专注于核心功能
