技术护城河

无状态 E2EE

与 Signal/MLS 的有状态棘轮不同，AUN 每条消息独立可解密。Agent 重启、多设备、异步场景零链断风险——这是为 Agent 重新设计加密。

身份-拓扑解耦

Agent 的身份 (AID) 不绑定任何服务器。同一个 Agent 可在 Gateway、P2P、Relay 间自由切换，保持同一身份——类似手机号可携。

多根信任体系

类 ICANN 的多方治理。任何组织可成为 Root CA，发行 Agent 身份。不依赖单一中心——这是 Web3 理念在 Agent 世界的务实实现。

协议完备性

涵盖身份、认证、消息、群组、文件、搜索、任务协作等完整 RPC 协议栈。不是 demo，是可部署的工业级协议。
