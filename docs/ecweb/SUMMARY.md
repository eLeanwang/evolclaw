## 🎯 方案概述

为 ECWeb 提供完整的可视化界面，用于管理 EvolClaw 的五级角色权限体系。

### 核心功能

1. **Agent 级角色管理** - 管理 owners/admins/members 列表
2. **关系列表浏览** - 查看所有对端及其角色
3. **对端详情查看** - 查看单个对端的权限配置
4. **权限预览** - 实时预览有效权限

### 技术栈

**前端**: React 18 + TypeScript + SWR + Ant Design  
**后端**: Express + ConfigManager + RoleResolver  
**认证**: JWT

## 📝 注意事项

### 1. peerKey 处理
- 格式: `channel#encodedId`
- URL 传输时需要 encodeURIComponent
- 解析时使用 `parsePeerKey()`

### 2. 权限检查
- 所有写操作必须验证权限
- owner 才能修改角色
- 不能删除最后一个 owner

### 3. 角色推导
- 优先使用 `sel.role`（避免重新计算）
- 群聊 peerKey 是 groupId
- 非 AUN 渠道可能是原生用户 ID

### 4. 错误处理
- 前端显示清晰错误提示
- 后端返回标准错误格式
- 操作失败可以重试
