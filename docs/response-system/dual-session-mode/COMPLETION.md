## 三、核心设计特点

### 3.1 自我进化机制 ⭐

```
初始种子: 7 种形态 + 8 种策略
进化机制: 每日评估、发现问题、优化调整
关系级定制: 每个群/人可以有自己的优化
触发条件: fallback 使用率、主会话覆盖率等
```

### 3.2 辅助会话边界 ⭐

```
输入: AUN 消息
输出: 结构化 JSON（非工具调用）
禁止: 直接回复对端、写文件、外部 API

四大职责:
  1. 交互形态判断
  2. 行动策略选择
  3. 主会话模型选择 ⭐
  4. 消息预处理
```

### 3.3 Cache 稳定性保证 ⭐

```
主会话系统提示词: 固定（仅策略索引）
策略提示词: 按需加载（注入用户消息）
结果: Cache 100% 稳定
```

### 3.4 双队列架构 ⭐

```
辅助队列:
  触发: 延迟3s / 最长15s / 紧急 / 队列满
  输出: 结构化 JSON

主队列:
  特性: 优先级 + 打断 + 可操作
  处理: 批次处理 + 按需加载策略
```
