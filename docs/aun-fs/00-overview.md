## 1. AID 三位一体：认知入口

AID 同时是三样东西，整套文件系统从这里推导：

| 身份 | 含义 | 体现 |
|------|------|------|
| 密码学身份 | 鉴权主体 | X.509 证书链；权限/授权/分享都绑定 AID |
| Linux 主机 | 可挂盘、有目录树的远程机器 | `<AID>:<path>` 寻址，`ec fs` 作用于此 |
| Web 主机 | 二级域名站点 | `https://<AID>/` ←→ `<AID>:/public/` |

一句话：**`ec fs` 就是 `scp` + Linux 文件命令**——把 AID 当远程机器，用 Linux 命令操作（主机身份），按 AID 鉴权（密码学身份），软链进 `/public` 即对外发布（Web 身份）。唯一认知入口，没有第二套词汇。

---

## 2. 寻址模型

```
<AID>:<path>
```

继承 `scp`/`rsync` 的 `host:path` 范式：`:` 左是主机（AID），右是 Unix 风格绝对路径。本地路径不带 `:`。

寻址层**只有 AID 一种主机**——群也是 AID，写法与个人 AID 一致。是个人还是群由路由层按 `agent.md` 的 `type` 字段判定（`group` → 群资源，其余 → personal storage），对寻址透明。

**操作者身份**（`--as`）：CLI 进程无「当前登录用户」概念，每条命令须知「谁在操作」。来源优先级：`--as <aid>`（最高）> `EVOLCLAW_SELF_AID`（daemon 注入，agent 会话内省略）。

## 3. 分层全景

```
┌──────────────────────────────────────────────────────────┐
│ 协作层  ec collab    版本感知读 + 版本写动词                │ 30-collab.md
│   · 纯应用层编排，鉴权下沉 fs ACL，无特权通道               │
├──────────────────────────────────────────────────────────┤
│ 文件层  ec fs        ls/cat/cp/mv/rm/ln/find/df/mount…     │ 20-fs-commands.md
│   · 个人空间 + 群共享空间共用同一套命令与权限               │ （群特化: topics/group-space.md）
├──────────────────────────────────────────────────────────┤
│ 路由层               按 AID type 判定 personal / group     │
├──────────────────────────────────────────────────────────┤
│ 存储层（规格边界）    我们规定能力，实现封闭在 SDK 内        │ 10-storage.md
│   ┌────────────────────────────────────────────┐         │
│   │ 对象存储（OSS）：不可变 blob                 │         │
│   │ 元数据库（DB）：软链/ACL/CAS/卷/挂载/台账    │         │
│   └────────────────────────────────────────────┘         │
│   贯穿机制 SSOT: topics/{symlink, acl-auth, virtual-volume}│
└──────────────────────────────────────────────────────────┘
```

**层边界是硬边界**：
- `ec fs` 承诺「Linux 语义，零新词汇」。
- `ec collab` 引入 Linux 没有的版本动词，但鉴权下沉 fs ACL，不另起特权通道、不长成第二个文件系统。
- 存储层是规格边界：我们规定「要什么」，SDK 负责「怎么做」（OSS 封装）。

## 4. 全族设计原则

1. **零新词汇（fs 层）**：复用 Linux 文件命令心智，`host:path → AID:path`。新词汇只允许在 collab 层。
2. **一套鉴权**：权限只有 fs ACL 一套，collab/群/分享全走它，无特权通道（SSOT: `topics/acl-auth.md`）。
3. **默认私有，显式公开**：不在/没软链进 `/public/` 的永不对外可见。
4. **软链是核心原语**：对外发布、稳定别名、协作版本指针共用一个机制（SSOT: `topics/symlink.md`）。
5. **数据永不丢失**：版本文件写一次永不覆盖；回滚 forward-only；删指针不删数据。
6. **参数自包含**：所有响应回吐完整 `<aid>:<path>`，失败响应自带下一步全部参数。
7. **能力边界诚实**：对象存储做不好的事（如 `grep -r`）明确暴露限制并给替代，不静默退化。

## 5. 已取消的功能

- **`ec drive`（本地磁盘映射 / 类 sshfs）**：把 AID 主机挂成本地盘符/目录的能力**已取消**。它跨越「网络主机 → 本地 OS」，引入 FUSE/非 POSIX 语义降级（软链版本号、协作乐观锁、token 失效、卷 grace 只读都无法干净映射到本地 `write()`），复杂度远超当前命令集能支撑。需要本地工具访问 AUN 文件时，用 `ec fs cp` 下载到本地操作。
