# EvolClaw 命令集目录

所有 `ec` 命令集的专属索引：用途、触发词、适用场景、详细文档。
运行时 evolclaw 会通过 `commands` fragment 按当前场景（有无 peer/group、对端角色）
注入一张精简能力卡，指向本目录下对应文档；需要完整用法时 Read 对应文档。

> 命令通用约定：以自己 AID 为发送者；必须走 CLI，不在会话里直接输出对外消息；
> `--format json` 所有命令通用；`--app <name>` 指定应用 slot（独立消费通道）。

## 如何使用本索引

1. **遇到触发词**（用户提到"费用/用量/创建/查群/上传文件"等）→ Ctrl+F 本文档找触发词 → 定位命令集 → Read 对应文档
2. **不确定有没有命令**时，直接 `ec <猜测的子命令> --help` 试一下（如 `ec stats --help`）
3. **已知场景需求**（如"要给对端发消息"）→ 看下方分类表 → 定位到对应命令集

## 服务运维类（本地，无需 AUN）

| 命令 | 用途 | 触发词 |
|------|------|--------|
| `ec --version` / `-v` / `-V` | 查看版本号 | 版本 |
| `ec restart` | 重启服务（含自动升级检查） | 重启 |
| `ec status` | 查看运行状态、进程、会话、渠道连接 | 状态/查看状态 |
| `ec logs` | 查看日志（`--level` `--module` `--raw` `--no-color`） | 日志/查看日志 |
| `ec diagnose` | 诊断启动环境 | 诊断/环境诊断 |

## 对外通信 / 网络类（连 AUN，以 AID 为发送者）

| 命令集 | 用途 | 触发词 | 适用场景 | 文档 |
|--------|------|--------|----------|------|
| `ec msg` | 私聊收发消息 | 回复/发消息/拉取/撤回/查在线 | 有对端（peerId） | `msg.md` |
| `ec group` | 群聊收发与群管理 | 群发/建群/邀请/踢人/退群/群成员/角色/封禁/规则 | 群聊（groupId） | `group.md` |
| `ec aid` | AID 身份管理 | 身份/证书/名片/探测对端 | 任意有渠道场景 | `aid.md` |
| `ec fs` | AUN 文件系统统一入口 | 上传/下载/看文件/列目录/删文件/配额/群空间 | 任意有渠道场景 | `fs.md` |
| `ec storage` | 文件存储底层调试入口 | storage 调试/旧命令/底层上传下载 | 任意有渠道场景 | `storage.md` |
| `ec agent` | EvolAgent 生命周期 | 创建/启停/热重载/改配置 | 管理员（owner/admin） | `agent.md` |
| `ec rpc` | 底层 AUN RPC（逃生通道） | 直接调协议方法 | 高级/兜底 | `rpc.md` |
